# 摸摸鱼设计笔记

2026-11-05 摸鱼空间：沿用framed-sheet（seed191592204），不新建视觉体系。独立导航支持吐槽、随手拍、心情，公屏保留三张紧凑摘要；照片封面和纯文字卡混排，示例明确标注且不伪造互动。桌面详情左侧完整照片画廊、右侧正文留言，支持照片和篇目两个层级的前后切换；窄屏上下排列、照片可横滑。发帖仅保留标题、正文、紧凑照片入口和留言开关，照片库按需展开；同事可见、匿名不替照片脱敏、仅文字审核在确认前正常字号说明。流式对话直接展示生成中的正文，不重复堆叠进度说明。

方向：沿用共享的 framed-sheet 方向。暖中性灰组成侧栏和顶栏的 L 型框架，白色工作纸承载内容；细边界、无投影，以鲜橙和深墨色构成品牌重点。默认卡片为暖白纸底、深墨字与局部鲜橙，个人卡片可选择其他安全主题。IBM Plex Sans 以本地字体文件加载，中文回退到系统中文字体。

用户确定的文案原则（2026-10-30）：说明按需要出现。标题、标签、按钮能表达的意思只说一次。密码格式、必填项和发布可见范围等关键规则，放在对应操作附近并在提交前说明；使用正常可读字号。重复的板块副标题和泛泛的引导小字应精简，次要细节可折叠。

用户新增原则（2026-11-06）：Avoid unnecessary secondary labels and descriptions. Let the layout do the explaining. 优先用布局、分组、间距和控件位置表达关系，不为已清楚的界面重复添加副标签或解释；影响操作成功和公开范围的规则仍在对应控件附近说明。

- 公屏：回答“现在有什么我能帮忙的事”。左侧连续滚动卡片与独立摸鱼空间；右侧依次为官方发布、员工文字需求列表，长列表在各自区域滚动。来源切换控制卡片墙，搜索同时筛选两类侧栏列表。鱼线图形、技能和时间信息呼应工作间隙的互助。演示标记来自后端isDemo，数量为当前筛选结果，不代表真实使用量。
- 澄清：回答“怎样把模糊的困扰交代清楚”。对话与可编辑卡片并列，窄屏顺序堆叠；本地规则模式明确标注 Dify 未连接，保存和发布使用真实接口。私密范围不能发布，确认弹窗说明公屏可见性。
- 我的工作：回答“之前的需求和接下的事在哪里”。四个标签对应需求、草稿、接取和已移除；草稿回到对话及编辑工作区。
- 详情：回答“这件事具体要做什么，我能接吗”。说明困扰、目标、交付和完成标准，只有符合条件的开放需求显示接取操作。
- 档案与认证：回答“别人如何知道我能帮什么”。注册与首次建档合一，设置页将说明与表单分栏；手机端上下堆叠。

Face：IBM Plex Sans + 系统中文字体。Signature：橙色抽象鱼线标志、暖灰 L 形框架与暖白需求卡上的橙色细节，技能和闲暇时间是信息主体。样例全部以服务端标识为准，未编造使用数或通知结果。

卡片可通过对话选择本地山景、海岸或表情包图片作为封面；正文保留实色阅读区。无背景卡片以文字层次和分隔线组织内容，不需要图片即可阅读。

用户希望每张需求卡有个人特色：固定形状支持标准、两侧凹口票根、相片边框和不对称气泡，可与安全背景组合；卡片文字始终位于实色阅读区。

2026-11-02：聊天改为可工作的双栏画布，对话与预览在桌面同高；暖灰预览纸台与白色聊天区沿用 framed-sheet，不增加营销式大标题。真实工具事件显示制作进度，支持表格、代码复制、停止与重试；错误时保留输入和原卡片。Agent 制作的 SVG 插画仅作顶部封面，正文单独排版，纸面文字自动保证高对比。新设计、草稿恢复、公屏、确认与详情共用同一份成品，形状仍由受控网页样式绘制。对话回复避免重复右侧完整卡片；窄屏上下堆叠，不把桌面布局改成手机壳。

2026-11-02 附件与交付：上传入口贴近聊天输入框，文件列表按需展开；背景公开、原件提供范围、匿名无法脱敏等规则在上传和发布前以正常字号说明。任务详情分“需求详情 / 材料与交付”，材料与历史提交沿用白纸、细分隔线和橙色操作，不另建装饰卡组。最新提交展开、历史折叠。本人未接取卡片编辑须确认公开保存；移除进入可恢复列表，接取后保护原始约定与提交历史。

2026-11-02 材料理解与侧栏：桌面侧栏固定为窗口高度并sticky，长公屏只滚动内容，不把账号区推到页面底部；小窗口保留侧栏自身滚动，窄屏沿用顶部导航。上传图片默认是需求材料，“AI阅读 / 随需求提供”分别控制模型读取与双方下载；明确选择才作背景，当前背景不供AI阅读。传入Dify/模型的说明放在上传控件附近，容量与历史不可收回规则按需展开。普通文件问答恢复后继续显示对话，不强行显示空卡片。

用户后续要求（2026-11-02）：图片/文件UI保持简约。聊天附件区采用紧凑单行，只显示上传、大小上限、附件数和AI阅读数量；文件清单及用途设置按需进入管理弹窗，详细规则折叠。不要在输入区常驻大块缩略图、复选项和长说明。

2026-11-02 直接办公：对话成为桌面工作区主体，默认全宽，需求预览按需开启/收起；输入框默认一行并随文字增高，上传继续采用紧凑单行及按需管理弹窗。只有一个位于页面右上的“转为互助需求”入口，避免重复引导。真实结果文件以回复内的紧凑下载行展示。普通办公对话及结果可在“对话与草稿”恢复；不为普通问答显示空白卡片。

2026-11-03 站内推荐：仍沿用 framed-sheet、暖灰侧栏和橙色重点。站内消息以可扫描列表呈现，未读使用一个小橙点及侧栏计数，不增加装饰卡组。档案增加折叠“推荐设置与空闲时段”；空闲时区、结束晚于开始和关闭推荐的效果用14px正常字号靠近控件说明。发布确认提前说明将向合适且愿意互助的同事发送站内推荐；预匹配阶段不通知。

2026-11-03 心理关怀：摸鱼空间独立于任务卡与人员推荐，采用简洁横向倾诉卡及独立详情；公开、匿名和反馈待处理的边界只在相关操作附近说明。助手按需展开匿名倾诉预览，紧急状态不显示公开引导。

2026-11-03 公屏密度：沿用framed-sheet（seed 191592204），橙色鱼线和流动需求卡作为产品特征。公屏任务卡统一256×200px，插画/图片封面44px，标题最多两行，封面卡摘要两行、无封面卡三行，点击详情保留全文；个人主题与形状仍有效。每四条需求分一行，最多三行，不再跨行重复铺相同需求；无缝循环副本保持辅助技术隐藏。心情卡统一160px高，右栏304px，官方/员工列表分开滚动；窄屏侧栏移至主区下方，官方在前员工在后。公屏样式集中在Board.css，不影响对话预览及任务详情的完整内容。

2026-11-05 附件扩容：聊天上传栏仍保持紧凑，仅展示单个50MB和本轮AI最多10个；附件管理继续折叠完整规则，说明每对话100个、个人1GB、每轮100MB，以及超量材料仅保存需分批选择。不新建大块说明面板。

2026-11-05 对话导航：站内页面切换不受生成/上传阻塞，顶部仅在离开工作区时显示当前回复状态和返回入口。返回AI办公保留对话、预览、输入及进度；明确“新对话”才重置。生成中只限制替换当前工作区，其他页面可正常查看和保存；退出清理本人私密现场。


2026-11-05 摸鱼空间重构：以图片优先的混排收藏墙替代三列等高方卡。正文便笺穿插于横竖封面之间；两列自然高度瀑布流加轻量私聊侧区，宽屏三列，窄屏顺序堆叠。沿用 seed191592204、暖灰框架、白纸、本地 IBM Plex Sans 和橙色操作。图片全部使用已有本地示例和真实上传，保留示例标记。

动效参考 Aceternity 官方 3D Card Effect / Sidebar / Focus Cards 的交互思路：鼠标微倾斜最多约1.5度、悬停浮起4px、图片缩放1.045；不加背景模糊。键盘保留明确焦点，触屏直接点击，减弱动效时取消透视、位移和过渡。桌面侧栏可手动收为图标轨道，窄屏改为抽屉，支持遮罩、Esc、焦点约束和关闭后恢复焦点。导航仅调用既有 go；不修改会话挂载、chatViewKey、生成隔离与退出清理。

2026-11-05 聊天排版：取消980px居中上限和用户气泡88%宽度限制，聊天消息使用工作区可用宽度与既有内边距。完整和流式回复共用同一Markdown配置，按模型提供的段落、列表、表格和代码块排版；段落单换行保留。宽表格仅在带键盘焦点的局部容器横滚，不扩大页面宽度。

2026-11-05 布局收紧：账号区以固定头像和可收缩姓名/部门列排版，折叠态仅头像，取消尾项通用样式的字号与自动边距。个人档案去掉空的左侧说明列，表单靠左使用可用宽度，姓名部门并排，其余字段完整排列。摸鱼空间全部筛选分栏改为Grid按行从左到右填充，保留图文差异与动效，不再使用纵向优先的CSS columns。

个人档案宽屏表单使用全部可用宽度，DOM依次按姓名/部门、技能/空闲、技能说明/简介双列组织；帮助意愿与推荐设置通栏。窄屏依次单列，注册仍使用原字段顺序。

2026-11-06 管理后台：沿用白纸与橙色操作，仅管理员侧栏可见。三个标签分别管理账号、公开内容、官方公告与悬赏；账号表格使用细分隔线，公开内容使用文字列表，不读取私密对话。角色、启停、密码变更及官方发布在确认处说明影响；密码格式和公开范围提前放于控件旁。

2026-11-06 官方设计与视频：官方编辑采用宽屏双栏，左侧内容和折叠设计选项，右侧共用安全主题/形状的实时成品卡；上传背景仅绑定确认后公开。摸鱼空间混合图片和视频保留9项/3视频限制，视频以播放块而非图片呈现，详情和确认中可控播放、下载并有解码失败提示。任务材料与交付视频在原文件列表按需展开，紧凑上传行区分50MB文件与200MB视频；视频不作卡片背景、不供AI读取，公开视频说明不做画面审核。

2026-11-06 账号与内容处置：账号行分别展示禁用、禁言、删除，删除前明确保留任务与交付并可恢复，恢复后仍停用；已删除行仅可恢复。管理员可在摸鱼空间详情删除帖子/留言，普通本人管理走原接口；内容管理可切换已删除列表再确认恢复。禁言只限制公开发布与编辑，保留私下对话与交付入口。

2026-11-06 互助积分：帖子卡片外独立点赞控件，演示内容只读；需求墙与详情并列悬赏积分和真实难度状态，不伪造失败评分。悬赏由发布者确认、接取后锁定，验收由平台一次性发放，不扣发布者余额。互助榜采用按行填充的前三名与真实排行表，切换本月/累计；本人记录单列摘要，无合成成绩。发布/接取确认处说明实名上榜及名额规则，名额从接口读取；任务交付区保留退回、重提、验收和完成积分记录。

2026-11-06 悬赏五分制：草稿、公开未接取卡与官方悬赏共用1～5分紧凑选择，默认1分。已接取或已完成的历史奖励与排行榜真实累计不做压缩或改写；AI难度仍独立显示，不乘算积分。

2026-11-09 界面整改：摸鱼空间卡片按行对齐，图片封面和纯文字便笺使用相同媒体高度，标题、来源与点赞固定在卡片底部；紧凑公屏和完整摸鱼空间共用同一节奏，文字便笺的正文、说明和点赞区使用连续底色。需求卡取消“编辑文字”开关，标题、正文、目标、交付物、完成标准直接在卡片文字位置编辑，技能与截止时间在卡底就地编辑，输入时增亮下划线和浅底色，仍保留折叠的“外观”和“更多设置”。我的工作为草稿和公开需求增加独立的移除入口，已移除列表可直接恢复，行按钮与行内操作分离；非参与者的需求详情不再显示只有一个选项的标签栏。公屏右栏改为单一滚动容器，官方发布与员工需求完整展示，摘要允许两行，卡片、表单、列表和提示的暖色边界整体加强，避免页面区域混在一起。
