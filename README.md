# 摸摸鱼 · 工作互助空间

面向电脑浏览器的本地网页应用：员工建档，把困扰整理成需求卡，确认后发布到公屏，由其他同事接取。采用 React + Vite、Node.js 原生 HTTP 和 SQLite；使用 taste-skill 的 Framed sheet 设计方向。

## 本地启动

需要 Node.js 24 或更新版本。

首次获取项目：

```powershell
git clone https://github.com/dirtybd/momoyu.git
cd momoyu
Copy-Item .env.example .env
npm ci
```

在本机 `.env` 中填写 Dify 配置；密钥、本地数据库和测试产物均不纳入 Git。后续使用 `git pull` 获取更新。

Windows 可直接双击项目根目录的 **启动网站.cmd**：首次缺少依赖时自动安装，前后端准备好后打开浏览器；如果网站已经运行，则直接打开，不重复启动。使用期间保留启动窗口，按 Ctrl+C 停止服务。

脚本会显示网站地址与浏览器打开结果，执行结束后保留窗口。若默认浏览器没有弹到前台，可手动访问 <http://127.0.0.1:5173>。批处理入口采用纯 ASCII，避免中文命令行解析问题；运行时提示支持中文。

也可通过命令行启动：

```powershell
cd D:\AI\momoyu
npm install
npm run dev
```

在电脑浏览器打开 <http://127.0.0.1:5173>。开发服务由前端 5173 与后端 8787 组成，按 Ctrl+C 结束。页面会随可用窗口宽度适配；要看完整桌面工作台，请使用宽屏浏览器窗口。

也可以构建后使用一个服务运行：

```powershell
npm run build
npm start
```

此时访问 <http://127.0.0.1:8787>。默认只监听本机，没有发布到互联网。

后续互联网访问的两种路线和当前代码需要补齐的部分，见 [互联网访问方案](docs/DEPLOYMENT.md)。

## 试用完整流程

1. 点击“登录 / 注册”，选择“注册与建档”，填写账号、至少 8 位密码、姓名、部门、技能和空闲时间。以后可在左下角个人档案修改。
2. 点击“发起需求”进入 AI 助手。普通办公问题可直接提问；需要找同事协作时，说明困扰、目标和交付物，右侧生成需求卡预览。展开“编辑需求内容”可补充技能、时间、匿名与可见范围。
3. 保存草稿，或点击“预览并发布”，核对卡片后确认发布。私密草稿只保留给本人，不能直接发布到公屏。
4. 公屏卡片统一为256×200px，按需求数量分1–3行交错滚动；悬停、聚焦、打开详情时暂停，也可手动暂停，减少动态模式改为静态横向浏览。右侧依次为官方发布和员工需求列表，分别滚动；搜索同时筛选两类内容。
5. 退出后注册第二个账号，找到刚才的需求，进入详情后接取。“材料与交付”里下载原始材料、上传成果并提交；发布者可验收或写明反馈退回，历史版本保留。
6. 在“我的工作”管理本人草稿和未接取卡片：编辑、移除或恢复。接取后的原需求锁定，发布者仍可补充材料。

首次启动会生成 10 条完整的“示例 / 演示”内容：6 条员工需求、2 条公告、2 条官方悬赏，包含目标、交付物与验收标准等。现有示例已补全；真实账号与需求由你自行创建。匿名只隐藏公屏中的发起人姓名和部门，需求正文仍由发布者自行核对。

卡片支持对话改配色、版式、字重、圆角、背景与轮廓。例如：“把这张卡做成海边拍立得，橙色主题，标题醒目”或“画一个星空山脉与帐篷的插画封面，改成票根”。配置制卡工具后，Agent 可自主设计 SVG 插画背景，网页接收实际工具成品；旧卡片继续支持预置风景与表情图片。设计随本人草稿保存，发布后在公屏与详情保持一致。可上传自己的照片/表情图片作背景，仍不支持照片生图或任意 CSS，详见 [自主卡片设计](docs/DIFY-CARD-TOOL.md)。

聊天区支持 Markdown、表格、公式与代码复制、实际工具进度、停止响应和失败输入恢复。Enter 发送，Shift+Enter 换行；需求卡片在右侧预览，确认后才发布。

## Dify 配置位置与当前边界

复制 `.env.example` 为 `.env`，设置 `DIFY_BASE_URL`、`DIFY_API_KEY`、`DIFY_TIMEOUT_MS`。当前本机地址为 `http://127.0.0.1:8080/v1`，应用密钥已经标识 Agent，无需再填写 Agent ID。密钥只由服务端读取，不会返回网页。修改配置后重启服务。

自主制卡另需配置 `CARD_TOOL_SECRET`（随机且至少 32 字符），网页后端和工具共用；本机已设置。`npm run dev` 会同时启动 8792 制作服务，Dify 通过私有接口调用它，不需要把网页应用密钥放进工具 Schema。迁移 Dify 时按上方文档导入工具、更新地址与精确网络规则。

**填写密钥后，需求澄清与卡片生成通过真实 Dify Agent 完成；密钥留空时使用本地规则。** `server/dify.mjs` 对接新版 Agent 的 `/chat-messages` 流式接口，区分增量与最终回复，严格校验卡片结构。每张草稿保存独立的远程会话，重启后可续聊；用户和不同草稿之间隔离。当前卡片、近期历史及附件元数据会发送给配置的 Dify Agent；勾选“AI阅读”的需求材料还会传入文件内容，供所配置的模型与会话沙箱处理。背景图不参与阅读，旧附件默认关闭AI阅读。

Dify 超时、断流、认证失败或输出格式异常时，网页显示错误，不自动改成本地回答，不覆盖原草稿。未配置时超时 180 秒；本地 `.env` 和配置示例为文件工作预留 600 秒。Agent 只更新需求文字和受限样式字段，匿名、积分、可见范围和发布状态始终由网页和后端控制；发布仍需本人确认。由于模型回复具有不确定性，发布前应核对生成内容。

要补充 Agent 的主提示词、计算工具、联网搜索或文件处理能力，见 [Dify 配置教程](docs/DIFY-AGENT-SETUP.md) 与 [可直接复制的主提示词](docs/DIFY-AGENT-PROMPT.txt)。卡片原图与生成提示词记录在 [素材说明](docs/CARD-BACKGROUND-ASSETS.md)。

未配置密钥时，本地规则支持逐轮补全，也支持带标签的输入，例如：

```text
问题：两份名单需要核对漏项
目标：找出缺失和重复记录
交付物：一份差异清单
完成标准：标明所在文件及行号
技能：Excel
截止时间：下周三
```

人员匹配已接入独立Dify工作流：先按空闲时间、互助意愿和接单量过滤，再由AI结合需求全文与员工明确填写的技能经验说明判断，返回可核对的原文依据。制卡只预匹配，确认发布后后端发送站内消息，后台每15分钟补查；个人可关闭推荐。见[匹配说明](docs/MATCHING.md)。

同一Agent支持办公与情绪支持分流。心情对话默认私密，明确要求后才生成匿名倾诉预览，本人再次确认并通过AI审核后进入独立摸鱼空间；支持鼓励留言、编辑、关闭留言、移除和反馈。情绪内容不参与人员推荐，不是诊疗或实时人工值守服务。见[摸鱼空间配置与边界](docs/CARE.md)。

普通文本办公问答已接通真实模型；本机Dify已配置计算、时间与公开网页读取工具，新部署需要重新配置。全网搜索尚未接通；图片与文档理解依赖模型和沙箱能力。已支持管理员账号管理、公开内容治理与官方公告/悬赏发布。附件交付、退回修改、验收、帖子点赞和平台积分结算已接通；悬赏1～5分、默认1分，难度由Dify独立评定1～5级，验收后一次性发放，月榜/总榜据真实流水计算。每人同时发布5项、接取3项，完成或未接取卡下架释放名额。站外推送、满意度额外奖励和积分兑换尚未接入。详情见 [积分与任务名额](docs/TASK-POINTS.md)。

人员档案、账号、会话、需求、对话和附件记录写入 `data/momoyu.sqlite`，文件保存在 `data/uploads/`，重启后保留。备份需同时覆盖数据库和 uploads，见 [文件上传与交付](docs/FILE-DELIVERY.md)。密码使用 scrypt 哈希，会话通过 HttpOnly Cookie 保存并在 30 天后失效。此版本用于本机低并发试用；公司范围部署还需要企业身份认证、管理权限和正式的网络部署配置。

## 验证与项目结构

```powershell
npm test
npm run test:e2e
```

浏览器测试使用本机 Microsoft Edge 和独立测试数据库，不污染 `data/`。默认不调用真实模型。覆盖注册建档、档案修改、多轮卡片流程、匿名发布、第二账号接取、刷新保留及窄屏兼容。后端测试还检查私密需求、越权编辑、重复接取、来源检查、会话失效与重启持久化；Dify 模拟测试检查流式中文、重复片段、会话隔离、错误不覆盖与并发修改保护。

- `frontend/`：网页与本地字体；设计记录见 `frontend/DESIGN.md`。
- `server/`：业务接口、数据库与本地需求引导。
- `docs/API.md`：前后端接口约定。
- `server-tests/`、`integration-tests/`：接口与浏览器测试。
- `.taste-skill/direction.json`：设计方向记录。

前后端协作会话均位于本项目，管理员负责接口协调与整体验收。


聊天输入框旁可上传 PNG/JPG/WebP/GIF、常见文档与工程文件，单个最多50MB。图片默认不向接取者提供原件，可选作公开卡片背景；勾选“随需求提供”的材料仅双方可下载。匿名只隐藏姓名、部门，不脱敏正文或文件。详情见 [文件上传与交付](docs/FILE-DELIVERY.md)。


AI阅读与“随需求提供”分别控制：前者把材料内容交给Dify及模型理解，后者控制接取者下载原件。每轮最多10个AI材料，文档最多50MB；图片使用去元数据的1800px预览，GIF首帧。图片默认是需求材料，只有明确选择或对话指定才作背景。压缩包、CAD/博图等工程文件仍可作为附件交付，暂不送AI解析。Agent可返回文本、表格、公式，也可生成和修改文件后提供私人下载。默认先直接工作；不能完成或结果不满意时，经用户同意再整理互助卡。对话与结果保存在“我的工作 → 对话与草稿”。

附件区采用单行工具栏，点击附件数量管理AI阅读、共享与背景用途，详细文件规则按需展开。

附件扩容：每对话最多100个，个人空间1GB；AI每轮最多10个、合计100MB。完整限制与Dify配置见[附件限制](docs/ATTACHMENT-LIMITS.md)。
