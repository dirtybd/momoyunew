# 账号与管理权限

普通注册固定为员工。权限来自独立的 `account_access` 表，客户端的角色、ID和档案字段不能改变权限；旧账号默认仍为员工。

| 操作 | 主账号 | 第二管理员 | 员工 |
| --- | --- | --- | --- |
| 创建、停用、启用员工及重置员工密码 | 可以 | 可以 | 不可以 |
| 创建第二管理员、授权或降级管理员 | 可以 | 不可以 | 不可以 |
| 停用或降级主账号、后台修改本人凭证 | 不可以 | 不可以 | 不可以 |
| 管理其他管理员 | 可以管理第二管理员 | 不可以 | 不可以 |
| 下架或恢复公开卡片、帖子、留言 | 可以 | 可以 | 不可以 |
| 发布、编辑官方公告和悬赏 | 可以 | 可以 | 不可以 |
| 读取他人私密对话、草稿、私人附件 | 不可以 | 不可以 | 不可以 |
| 编辑或移除本人帖子、未接取求助卡 | 可以 | 可以 | 可以 |
| 提交接取任务的成果、验收本人任务 | 按参与者身份 | 按参与者身份 | 按参与者身份 |

管理员总数包含主账号，最多两名；停用仍占名额。主账号可将第二管理员降为员工后重新分配。数据库唯一索引保护单一主账号，插入与更新触发器保护管理员数量上限。禁用、密码重置、角色变更立即撤销目标的已有登录会话。账号删除采用可恢复的软删除，既有任务和交付记录保留；账号标识占用保留，不允许重新注册冒用原账号。删除强制退出、清除管理员角色，恢复后保持停用与员工角色，需另外启用和授权。

公开内容下架使用独立的管理状态，和作者自主移除区分。下架后停止公屏展示、推荐和新接取；已接取的双方仍可访问原任务工作区完成交付。帖子下架同时撤销他人对照片的读取，原作者仍可读取本人的照片。管理下架与删除分开记录；管理员可从内容管理的已删除列表恢复帖子或留言，恢复删除不自动解除下架，也不恢复未公开草稿。管理操作记入 `management_audit`，不保存密码或完整操作请求。

官方悬赏沿用真实接取、材料交付与验收流程；官方公告不可接取。接取后禁止重写原始约定，管理下架不删除协作记录。官方悬赏与员工需求均可设1～5分奖励，验收后平台一次性发给接取者，不扣发布者余额；难度1～5独立记录。公告不占任务名额，官方悬赏计入发布者5项上限。

首次部署先启动网站完成数据库迁移，再在项目目录运行：

```powershell
node scripts/bootstrap-admin.mjs --username <主账号>
```

命令交互输入初始密码，不回显、不通过命令行参数或配置文件保存密码；数据库只保存随机盐和 scrypt 哈希。已有主账号时命令拒绝重新初始化，不重置密码。第二管理员由主账号登录“管理后台 → 账号管理”创建。主账号和管理员界面都保留正常员工办公与互助入口。


## 禁言、删除与图片背景

账号禁言记录在account_restrictions，普通员工不可修改。主账号与当前登录管理员不可被后台禁言/删除，副管理员只能管理员工。禁言者仍可登录、建档、私密办公、下载材料及交付/验收已有任务，但不能发帖、留言、发布新需求或修改/恢复公开内容；内容审核完成后再次检查禁言，防止审核期间禁言后继续公开。管理员的内容治理权限与禁言分离，官方发布仍受禁言限制。

删除账号强制撤销会话并停用登录，任务、附件、公开内容与审计保留，未代替内容删除。若需隐藏已有帖子，可单独删除或下架。删除/恢复写入management_audit；恢复账号不恢复旧会话。管理员在摸鱼空间可直接删除公开帖子/留言，普通员工仍只能管理自己的帖子，以及本人或自己帖子下的留言。删除帖子撤销他人对图片/视频的访问；上传者保留私人访问。

官方发布支持安全枚举配色、版式、形状及上传图片封面。暂存图片归上传管理员所有，不接受任意外部URL、CSS或SVG；另一管理员可保留已发布背景编辑文字，但不能偷用未发布背景。
