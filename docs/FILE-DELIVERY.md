# 背景上传、文件交付与卡片管理

## 使用入口

1. AI 助手输入框旁点“上传图片或文件”，可先上传再说明需求。聊天只显示紧凑的上传入口和附件数量，点附件数量进入“管理附件”。图片默认按需求材料处理，支持根据截图内容提问。作背景时在管理面板点“设为卡片背景”，或明确告诉 Agent 用哪张图片作背景。
2. 草稿/待接取图片默认不提供原件；普通文档默认勾选“随需求提供”，发布前可调整。背景预览会随卡片公开，附件原件仅发布者及接取者可下载。未勾选的原图仅本人可下载。
3. 发布后进入详情，接取者在“材料与交付”下载材料、上传成果、填写说明并提交。上传成果尚未提交时仅自己可见。
4. 发布者下载最新版本，确认验收完成，或填写具体反馈后退回修改。重新提交生成新版本；旧版文件与反馈一直保留。验收不发放积分。
5. 本人草稿可继续对话修改；未接取公开卡片在详情“编辑卡片”中保存公开修改，可换标题、正文、形状、版式、匿名和上传背景。移除后进入“我的工作 → 已移除”，可恢复。接取后不能改原需求或移除任务，但发布者可补充材料。

匿名只隐藏发布者姓名与部门，不隐藏正文、文件名或文件内个人信息。发布前需自行检查。公开公屏目前允许未登录浏览，因此背景预览也按该范围公开。

## 文件规则

- 单文件50MB，个人原件合计1GB；软移除不释放配额，防止不断上传绕过磁盘限制。
- 每需求最多100个有效材料附件；每次待提交成果最多20个。历史版本不占待提交数量。
- 接受 PNG/JPG/WebP/GIF、PDF、Office、TXT/CSV/Markdown/JSON/XML、ZIP/7Z/RAR，以及常见 CAD/三维/博图归档扩展名。不能上传网页、脚本或可执行文件；完整白名单在 `server/attachments.mjs`。
- 图片解码验证并生成最长边1800px的WebP预览，去除EXIF等元数据。GIF使用首帧。原件不改写，仍按权限下载；预览作为背景会裁切适配卡片。
- 已接取后的原始材料和已提交成果不能删除或覆盖，补充时上传新文件。任务被接取后，在“材料与交付”补充的图片也直接提供原件给接取者。卡片“移除”为软移除，保留数据库、附件与恢复能力，不做永久清理。

## Dify 与数据位置

既有 `design_card` 继续生成 SVG 插画；没有新增照片生图服务，无需配置生图密钥。实际主提示词备份为 `docs/DIFY-AGENT-PROMPT.txt`。

勾选“AI阅读”的需求材料通过Dify原生文件接口传入，可用来澄清需求、总结内容、解释文档、计算/核对表格并回答问题。图片以去元数据预览传入，文档按原件传入。内容由所配置的模型与Dify会话沙箱处理，不加入共享知识库。只有已明确要求作背景的图片才通过合法 `coverAttachmentId` 采用，截图需求不会自动变成背景。

“AI阅读”和“随需求提供”是独立选项；可只让AI分析，也可只交给同事。每轮最多10个阅读材料，文档最多50MB、图片预览最多10MB。旧上传文件默认关闭AI阅读，由本人手动开启；新草稿前10个可读材料默认开启，之后仅保存，需本人分批选择，发送消息时才传入。当前背景不参与阅读，移除背景后不会自动恢复阅读。

取消阅读不再向后续请求传入该文件，但不能收回本会话已读取的内容。格式解析与视觉能力取决于模型和工具：扫描件、小字、加密文件可能需要更清楚或可编辑的材料；CAD/博图、压缩包等目前只作为任务附件。Agent不执行宏或文件内命令，也不能自动修改原件、发布任务或提交验收。可返回文本、表格、公式与真实生成的文件；文件在对应助手回复下方私人下载，修改另存新版本。图片处理使用去元信息的1800px预览（GIF首帧），不保证原图分辨率。

Dify内需启用 Chat功能→文件上传、允许 image/document 和 local_file；本机已启用，当前每轮数量为10。模型需具备视觉能力来理解图片，文档通过沙箱实际读取。迁移配置参考 [Dify文件上传](https://docs.dify.ai/en/api-reference/files/upload-file) 与 [新版Agent](https://docs.dify.ai/en/self-host/use-dify/build/new-agent/build)。

上传记录和提交历史存于 `DATA_DIR/momoyu.sqlite`，原件与预览存于 `DATA_DIR/uploads/`（默认 `data/uploads/`）。备份/迁移需停服务后一致复制整个 DATA_DIR，或使用一致性在线备份方案；不能只备份SQLite。不要将真实附件、数据库、.env推送到Git。

个人配额计上传原件及AI结果文件，预览另占空间。当前为受控本地试用；公网需另补企业访问控制、总上传并发限制、磁盘监控和恶意文件扫描。尚未做压力测试。

## 直接工作与私人结果

进入“AI 办公”直接交代任务，或上传材料后提问/要求修改。默认全宽对话，输入框随内容增高；“转为互助需求”才开启建卡，生成卡片后可随时收起预览。普通对话也保存在“我的工作 → 对话与草稿”。

Agent可生成Word、修改指定文字或Excel单元格、合并PDF、把图片一图一页合PDF。实际生成并核验后，回复下方显示文件下载。源材料不覆盖，新旧结果均保留，结果仅本人下载，不自动成为公开卡片或接取者材料；需要交给同事时下载后自行上传为任务材料。复杂Word文本框/域/修订、旧doc/xls、加密和宏文件不保证处理；Excel公式需在Excel/WPS打开后重算。

单轮最多5份结果，每份20MB、总计50MB，结果计入个人1GB空间。图片工作使用去元信息的1800px预览，GIF仅首帧，适合整理阅读，不能视为原图无损加工。Agent无法完成或结果不满意时可以继续要求修改，或同意转为互助需求；发布仍需本人确认。
