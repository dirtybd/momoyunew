# 心理关怀前端交接（2026-11-03）

- 公屏“心情角”独立于任务列表；游客只看到登录入口。登录后读取 `/api/care/posts`，支持横向滚动、分页、详情、分页留言、审核后发表、本人编辑和移除、开启/关闭留言，以及本人或发布者移除留言和反馈不适。反馈文案仅表述待处理，不声称人工已响应。
- AI 办公使用 `/api/clarify` 返回的 `intent`、`carePreview`、`careSafety`。普通关怀不自动显示卡片；当 care 且非 urgent 时可明确请求整理匿名倾诉。独立预览可修改文字和留言开关，确认后仅调用 `POST /api/care/posts`，附本人对话 ID；urgent 隐藏公开引导。恢复对话时从 request 的 careMode/carePreview/careSafety 还原。
- 公开提示在发帖、编辑和评论控件附近出现；关怀区明确说明不提供诊断或用药建议。个人档案新增 `skillDescription`，注册及保存均提交该字段；`bio` 仍是独立字段。
- `npm run build` 通过。未启动服务、未对接尚在实现中的 care 后端做浏览器端到端验证；请主会话重点验证 SSE 的 care 字段、审核失败和 urgent、空数据/分页、留言权限、恢复对话及匿名公开规则。
- 前端控件：“心情角”“整理成匿名倾诉卡”“预览并确认发布”“确认发布”；详情内“编辑”“关闭留言”“移除倾诉”“反馈不适”。

- 反馈原因已改为必填。心情角使用真实列表在可滚动范围内低速往返，无复制卡片；悬停、焦点、打开详情、手动暂停和减弱动效均停止自动滚动。
- 模式切换约定：`intent=help` 与 `request` 均退出关怀 UI，私密 carePreview 保留、不显示；后端须同步持久化 `careMode=false`（目前 `server/index.mjs` 仅 request 清除），否则刷新恢复时仍会回到关怀模式。普通办公文件路径保持不变。

- 心情角“聊聊心情”开启新的空白私密会话，不自动发送；关怀模式显示倾听文案，help 返回办公文案。倾诉与留言公开前明确提示所提交文字由已配置的 AI 服务审核。
