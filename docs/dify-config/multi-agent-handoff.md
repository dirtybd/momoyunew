## 历史能力检查（2026-11-05）

以下是搭建前的能力检查；其中对待验证事项的描述反映当时状态，当前验收结果见后文。

- 当前 API 镜像为 Dify 1.18.0。Workflow 的添加节点菜单提供 Agent BETA，可选择已有 Agent；新版节点标识为 `type: agent`、`version: "2"`、`agent_node_kind: dify_agent`。节点任务配置使用 `schema_version: 1`，包括 `workflow_prompt`、`previous_node_output_refs` 和 `declared_outputs`。
