# 独立情感支持

统一Chatflow入口#4的care分支使用独立、无工具的情感LLM直接流式回答，读取本人隔离的care_text。原momoyu_care Workflow及独立Agent保留于工作室和旧入口发布版本，供管理员回退；办公文件与卡片专业分支、原Agent回退保留。关怀分支不挂制卡、人员匹配、文档或发布工具，也不生成交付文件。

## 对话与预览

1. 私密倾诉默认只返回情绪支持和一个可选择的问题，不自动生成公开内容。
2. 用户明确想分享或整理匿名心情卡时，Agent返回去标识的careCard，网站保存为本人私有预览，可在网页修改。
3. 用户点“预览并确认发布”，查看准确文字及同事可见/匿名边界，再点“确认发布”。后端沿用本人会话检查和独立内容审核，通过后才写care_posts；审核服务不可用时不发布。
4. 用户撤回分享时，Agent返回clearCarePreview=true；后端清空私有草稿。已经发布的卡片需本人在摸鱼空间用“移除倾诉”处理，撤回草稿不等于撤回已发布内容。

心情卡独立于任务、积分和人员推荐。Agent不能通过聊天替用户公开；确认发布的内容才送公开审核，不发送完整私密聊天。鼓励留言也继续单独审核，发布者可关闭留言、移除本人帖子及不适留言。

网页“聊聊心情”首次发送携带entryMode=care，后端把新会话设为关怀模式，简短问候也有正确默认方向；已有会话不能用此字段覆盖状态。后续明确转办公仍可切换，保留的心情草稿不会抢占办公标题续改。

## 上下文边界

- 新消息在messages.intent记录本轮类型，同一轮的用户和助手消息一起标记；展示接口仍只返回本人可读的角色/正文与附件。
- context_file只含已标记为help/request/style的最近工作历史、当前任务和授权材料；care_context_file只含关怀历史、当前心情草稿和安全状态，不含任务、员工档案、文件下载引用、制卡或匹配令牌。
- 路由器只看当前用户消息、必要状态和已脱敏的历史摘要；过去的关怀正文不会传给路由器。care工具只绑定care_context_file，不绑定工作context_file或sys.files。
- 旧版未标记类型的历史不会自动传给新办公/卡片Agent；本人网页历史保留，成果仍可通过outputHistory继续修改。旧关怀会话处于careMode时，未标记历史仅用于本人关怀连续性，不发给工作分支。管理员切回原Agent仍采用原有会话协议。

“私密”是网站的本人账号权限及不自动公开，不表示端到端加密或绝对保密；Dify、所配模型和系统管理员的实际数据权限仍需部署方管理。

## 输出与安全

Workflow三字段为answer_json字符串、deliverables=[]、artifact_json=""；Chatflow确定性封包route=care。后端只接受care意图，拒绝文件或插画工件。网页JSON沿用careCard/careSafety/readyForPreview，新增可选布尔clearCarePreview，兼容旧协议。

迫近危险优先支持即时安全和真人帮助，careSafety=urgent时清空预览、阻止公开和任务发布。当前对话的urgent状态不由Agent自行解除；分类器对已标记urgent的会话强制走care。没有配置经核实的本地热线查询工具，Agent不给出猜测的热线号码，也不会自动联系人员。

支持方式参考[WHO心理急救指南](https://www.who.int/publications/i/item/9789241548205)的倾听与实际支持原则，以及[NIMH危机支持步骤](https://www.nimh.nih.gov/health/publications/5-action-steps-to-help-someone-having-thoughts-of-suicide)中的倾听、安全与连接真人支持。它们用于约束产品回应方式，不构成对本产品的临床认证。模型路由、去标识和风险识别仍可能出错；本功能不提供诊断、用药或紧急救援服务。

旧路径真实合成验收记录见dify-config/care-agent-e2e-result.json，#4流式数据见dify-config/streaming-community-result.json及VALIDATION.md。新路径单轮倾诉首字约7.8秒、全答约10.5秒，实际速度仍随模型波动；网页支持停止等待，不能据此保证适合紧急场景。没有进行临床评估、长期干预效果或企业压力测试。

## 摸鱼空间图文社区

支持吐槽、随手拍、心情，不必先进行情感对话。可以直接写文字或发照片，也能继续使用Agent整理的匿名预览。所有发布都经过准确内容预览和本人确认，文字独立审核；尚未配置图片内容AI审核，因此在控件附近明确提醒检查人脸、工牌、文件等照片内容。

每条最多9张、单张20MB，仅接受真实PNG/JPEG/WebP/GIF，重新编码为静态WebP并去除EXIF等元信息（不自动遮挡画面中的人脸或文字）。暂存及未选择照片只对上传者开放；同事仅能读取已确认且未移除帖子的关联照片。编辑移除照片会恢复其私有状态；移除帖子会撤销他人照片读取权限。照片和任务附件共用个人1GB容量。

独立摸鱼空间入口和公屏摘要展示明确标注的客户端图文示例，不写入真实员工数据，不伪造留言。真实帖子仍只对登录同事可见。桌面详情左图右文，支持翻图、切换篇目、留言与本人编辑；窄屏上下排列，照片可横滑。
