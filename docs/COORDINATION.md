# 协作安排

用户授权管理员创建前端和后端会话并协调开发。

- 前端会话只编辑 frontend/，遵循 taste-skill 的 app-screen 流程与 .taste-skill/设计方向；避免修改API约定。
- 后端会话只编辑 server/、server-tests/；为根管理员提供所需配置说明。
- 管理员维护根目录依赖、Vite、启动脚本、docs/及浏览器端到端验证，协调接口变更。
- 接口以 docs/API.md 为准；需要修改时先说明实际原因。
- 数据仅使用本地样例和本机测试账号；不连接真实人员资料或发送消息。

2026-11-03：用户授权在匹配工作流与站内推荐功能中使用虚拟员工联调。Dify站内会话“负责 Dify 站内操作”负责工作流/工具/提示词与实际发布，主会话负责本地数据服务、队列、站内消息、前端及联调测试。仅处理本人确认发布后的站内推荐，不发送站外消息；真实员工档案只取匹配必要字段，不进知识库。
