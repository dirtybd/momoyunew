## 翻译路径

完整DOCX、普通XLSX和文字PDF由后端读取、按段提取、分批调用公司翻译Workflow的document_payload_json分支并写回副本。模型只返回翻译内容，不下载原件、不生成文件、不调用Skill或多轮文件Agent。TIA User Texts仍优先使用原按语言列补译路径；TXT保留单次纯文本路径。未明确目标语言先本地追问，下一轮“英文”继续处理。

- Word：翻译正文、表格、页眉页脚、脚注尾注的文字，保留原OOXML样式/图片/关系及段落结构。使用受控s0/s1等标记保存run边界，写回前验证标签完整、顺序及纯文本；不把模型XML插入文件。翻译变长可能改变换行分页；域、删除修订等不翻译。
- Excel：翻译文字单元格，保留公式、缓存、数字日期、样式、列宽、合并、图表。共享字符串追加译文并仅更换普通文字单元格引用，避免改到公式缓存。图表内文字、工作表名和公式内字符串不翻译。
- PDF：保留每个原页，在其后附对应译文页，正常字号自动换行分页；译文另页，不承诺原位替换。拒绝扫描/混合扫描、不可读编码、交互表单、加密、损坏或超限PDF；无OCR，不交付空白译文。

首版处理整篇/自动范围；指定局部范围、其他复杂格式保留既有办公路径。旧DOC/XLS和含宏XLSM需另存为无宏DOCX/XLSX；数字签名/宏包不自动写回。混合不支持文件不会被静默丢弃。

## 限制及安全

一次最多5份、单个20MB；段落最多3000字符，每批最多12段/3000字符，串行调用，同文去重。模型每批90秒，整组模型调用最多5分钟，不自动重复整个任务。总源字符最多16万、段落最多2000，过长请拆分。格式标记丢失、空译文、错ID、缺条、未知条目或网络失败时，整组不交付半成品；原件与既有结果保留。模型只接收用户允许AI阅读的文字。

所有结果进入既有assistant_outputs/私人下载链路，本人/任务/角色鉴权不变；后续修改会按需将本地产物上传一次取得真实Dify引用并缓存，local_file/tool_file区分处理。
