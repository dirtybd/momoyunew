# 心理关怀后端交接（2026-11-03）

- `server/care.mjs` 独立建表并提供契约中的帖子、评论、软移除、关闭评论及待处理举报；列表游标基于行号，每页20条。全部需登录，响应不返回作者身份。发帖及修改文字、留言由 `server/content-review.mjs` 审核；不可用时503且不写入，拒绝或危机为422。发帖/文字修改与留言分别限制每人每分钟5次（含审核失败尝试）。
- Agent 支持 `intent=care`、`careCard` 和 `careSafety`，关怀预览和安全状态只在本人草稿及澄清响应返回；危机清空预览且绑定该对话的发帖被阻止。关怀模式不得走普通需求发布及预匹配。本地有限关键词仅作提示，不能替代专业危机识别。未连接AI时的关怀回复明确为本地引导。
- 用户档案增加 `skillDescription`（最长2000字）；匹配预览兼容旧摘要及新增文字字段。无真实心理内容或真实人员资料参与本轮验证。
- `node --test server-tests/care.test.mjs` 合成数据覆盖匿名权限、审核错误、危机处理、软移除、关闭评论、举报、限频、草稿恢复及公开隔离。完整 `npm test` 在本轮通过，随后的小调整另跑了关怀专项测试。
- 限制：审核与Agent的安全识别依赖模型，不代表临床判断；本项目没有人工监护或紧急响应服务。上线前需与前端及线上工作流完成联调并复核；本会话未调用线上Dify、未修改现有业务数据库。
