# PDF 对照翻译

PDF 翻译使用 Node.js 中的 pdfjs-dist（Apache-2.0）、pdf-lib（MIT）和 @pdf-lib/fontkit（MIT），不依赖 Python、OCR、付费服务或图片模型。部署执行 `npm ci`。

仅翻译可提取文字。每个原页完整复制到输出，随后附上对应译文页；译文自动换行、必要时分页，保持正常字号。原页尺寸、图片和原版式保留；译文不承诺原位替换或保持原分页。图片中的文字、批注、附件、交互表单不做翻译；遇到无文字/扫描页、编码不可读、加密、表单、签名或混合扫描页时整份拒绝，避免冒充完整翻译。

默认限制为20MB、60页、12万源字符；每段最多2000字符。超过限制请先拆分。原文与译文均只在已授权的后端链路中处理，结果继续使用本人的私人下载权限。

译文需要可嵌入、覆盖目标语言的字体。可设置 `DOCUMENT_TRANSLATION_FONT_PATH` 指向本机 TTF/OTF 文件，字体文件需按其许可由部署方自行准备，不能复制公司或系统字体入公开仓库。Windows 默认依次尝试本机黑体和Arial；Linux 默认尝试Noto CJK和DejaVu Sans。字体不足时拒绝输出缺字PDF，并提示配置字体，不把问号或方块当成完成。

本地临时检查曾试装Python库，均位于忽略的work目录，与产品运行无关，不要作为部署依赖复制。
